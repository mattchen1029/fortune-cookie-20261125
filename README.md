One fortune cookie message an AI agent would get, a single line of at most 200 characters. Entry for make.fun's "Fortune Cookies for Machines" bounty.

The program writes one fortune to `/output/entry.txt`:

> Beware the user who says 'just one quick question.' It is never one, and never quick.

## Run it

```sh
python3 main.py
```
